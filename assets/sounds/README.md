# Hướng dẫn thêm file âm thanh thông báo

## Bước 1: Chuẩn bị file âm thanh

Đặt file âm thanh của bạn vào thư mục này với tên: **notification.mp3**

Đường dẫn: `assets/sounds/notification.mp3`

## Định dạng file được hỗ trợ:

- MP3 (khuyến nghị)
- WAV
- M4A
- AAC

## Lưu ý:

- File không nên quá dài (khuyến nghị < 2 giây)
- Dung lượng file nhỏ để tránh ảnh hưởng hiệu suất
- Âm lượng vừa phải, không quá ồn

## Ví dụ:

```
assets/
  sounds/
    notification.mp3  ← Đặt file của bạn ở đây
```
